


Repeater enables us to:
 - modify and resend intercepted requests to a target
 - send them repeatedly (nobody expected the spanish inquisition)

Interface sections:
 - request list (the "tabs" on the upper left)
 - request controls (right of the Send button)
 - request / response views (main area)
 - inspector = analyze & modify requests (easier than raw editing, right-hand side)

you can edit basically anything in the request, including:
 - request query parameters (mainly GET requests)
 - URL (eg. testing traversal, injection)
 - body (only POST requests)
 - method (GET, POST, PUT, DELETE, ...)
 - headers

Workflow
 - setup foxyproxy or whatever (port: 8080, hostname: 127.0.0.1, type: http (https can cause problems, refer to a better guide))
 - intercept a request in Proxy
 - send to repeater (right click or Ctrl+R)
 - you have to Send to get any response (becuase of the proxy)
 - analyze the request and response
 - modify the request (eg. change a parameter, add a header, try different URL)
 - send again and analyze the response
