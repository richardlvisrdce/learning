IIS

 - Microsoft's web server platform built into Windows Server
 - hosts websites and web apps, is on almost every Windows Server
 - exploited by Lazarus, still has unpatched CVEs that are actively exploited

IIS Short Filename (Tilde) enumeration
 - Windows Server defaultly has short filename (8.3) (inherited from DOS)
 - 8 characters for name, 3 for extension
 - a path that matches a real file has a different HTTP status code or response size than a non-match
 - this really helps attackers' directory enumeration and hidden files
 - affects IIS 5.x through IIS 10.0, including current versions on Server 2022. Microsoft has declined to patch it
 - we used iis_shortname_scan.py
